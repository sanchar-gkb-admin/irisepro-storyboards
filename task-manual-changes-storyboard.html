A Remove the redundant “Instructions” card on the task screen

On the task screen a student sees Description, then Instructions, then What to submit — three cards back to back. Sutirtha flagged Instructions as repetitive. We verified this against all 246 live tasks.

Verified: the Instructions text is a redundant restatement for 238 of 246 tasks (the real task lives in Description; the format is in What to submit). 8 tasks carry an artifact-length limit (e.g. “90-second video”) that today lives only in Instructions — those move into What to submit first, so nothing is lost. Then the card is removed for all.
